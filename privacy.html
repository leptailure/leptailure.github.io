Confidentialité

Leptailure est un portfolio personnel hébergé sur GitHub Pages.

Mesure d’audience facultative

Si vous acceptez, le site envoie l’adresse de la page consultée à un service de statistiques opéré séparément. L’adresse IP est utilisée temporairement côté serveur pour produire un identifiant pseudonyme valable pour une journée UTC. L’adresse IP complète n’est pas conservée dans la base de données. Le pays et, lorsqu’elle est disponible, la ville approximative sont estimés à partir de la connexion. Aucune géolocalisation GPS n’est demandée.

Ces informations sont utilisées uniquement pour mesurer la fréquentation de ce site, ne sont pas revendues et sont supprimées au bout de 30 jours. L’identifiant journalier ne représente pas forcément une personne distincte. Les services techniques utilisés comprennent GitHub Pages et, une fois activé, Cloudflare Workers/D1.

Le suivi est désactivé tant que vous n’avez pas accepté. Votre choix est conservé localement dans le navigateur, et peut être modifié ci-dessous.
